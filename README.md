# 知办 · NotiDo

*From Notices to Action.*
**让通知成为行动。**

知办将通知里的本人事项、真实截止日期和提交要求整理为滴答清单任务，并把相关原文件保存到任务的原生附件区。首版面向东北大学学生的个人使用，通过微信 ClawBot 与 QQ 官方机器人接收用户主动提供的材料。

当前处于需求设计阶段，仓库包含 PRD、审阅记录和待执行验收基线，尚无可运行插件或部署镜像。中国版滴答原生附件 CLI 路径及两平台真实能力需要阶段零验证。

## 首版范围

- 读取通知正文、截图与 PDF/DOCX/TXT，按身份识别本人行动。
- 自动记录明确的必做事项；自愿报名、关键条件不明时追问。
- 写入滴答原生截止日期及必要要求，相关原件上传到原生附件区。
- 支持新增、查询、修改、完成，以及重复通知、延期、部分失败和重启恢复。
- 使用 AstrBot 专用插件 `astrbot_plugin_notido`、受控 CLI、SQLite 与 Docker Compose。

官网采集只预留禁用接口；自动准备工期、周期任务、多人账号及定时主动提醒列为后续扩展。

## 开发起点

先按 PRD 第 13、25、26.7 节验证平台入口、任务 CLI、中国版原生附件和持久恢复，记录准确版本与脱敏证据。可独立实现领域规则与本地持久化；完整首版须通过全部核心门槛与验收。运行命令将在实际源码与部署验证完成后提供。

公开仓库只保存源码、需求和脱敏测试材料。账号凭据、真实通知与运行数据存放于受保护的部署数据目录。
